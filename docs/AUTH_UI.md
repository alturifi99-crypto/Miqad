# واجهات المصادقة

أعيد بناء المصادقة في `/console` كشاشات مستقلة عبر `#login` و`#signup` و`#forgot`، مع فتح شاشة إعادة التعيين عبر رابط البريد الحالي `#reset=...`. بقيت نقاط API والجلسات والصلاحيات وحدود المعدل والتحقق بالبريد وMFA كما هي. روابط التأكيد والاستعادة الحقيقية تتعامل معها security.js، وتزيل الرمز من عنوان المتصفح؛ انتهاء الرابط واستهلاكه مرة واحدة وإبطال الجلسات عند تغيير كلمة المرور تبقى مسؤولية الخادم.

التصميم: خلفية #F8F9F7، نماذج بيضاء، أخضر #4D7768، نص #252B29، حدود #E5E9E6. عمود بصري يمثل مخطط المقاعد على الكمبيوتر، ونموذج واحد على الآيفون والآيباد دون العمود البصري. خط Noto Sans Arabic مضمّن محليًا بصيغ WOFF ونسخة رخصة SIL OFL؛ لا تُرسل طلبات خطوط خارجية.

النماذج تشمل إظهار وإخفاء كلمات المرور، autocomplete مناسبًا، تحقق تأكيد كلمة المرور قبل الإرسال، متطلبات 12–128 محرفًا المتوافقة مع الخادم، رسائل واضحة، حالات تحميل مع تعطيل زر الإرسال أثناء الطلب، وروابط تنقل فعلية. الشروط والخصوصية تعرضان نصين داخل نوافذ dialog قابلة للإغلاق بلوحة المفاتيح. لا تُرسل كلمة المرور المؤكدة إلى الخادم.

«تذكرني» موضح بأنه يحفظ البريد فقط في localStorage تحت miqadRememberedEmail. لا يُحفظ فيه رمز جلسة أو كلمة مرور أو رمز دخول، ولا تتغير مدة الجلسات القائمة. إلغاء الخيار يمسح البريد المحفوظ.

الاسم والموافقة في نموذج التسجيل الجديد يُتحقق منهما على الخادم؛ يُحفظ الاسم ووقت الموافقة وإصدار النصين في سجل audit_logs الموجود للشركة، بواسطة دور تشغيل الشركة مع سياق RLS. لا يوجد جدول جديد أو تغيير في مخطط القاعدة أو تعديل للمستخدمين الحاليين. تبقى طلبات التسجيل القديمة دون الحقول الإضافية متوافقة. وضع التطوير غير المحمي يقبل الحقول الجديدة للتوافق، ولا يُستخدم للإنتاج.

التحقق:
- نجحت اختبارات الخادم الـ39 الخاصة بالمصادقة وعزل الشركات والحجوزات.
- نجح email-login-browser.cjs في وضع beta مع إرسال وهمي ونقل HTTPS معترض: التسجيل بالنموذج الجديد، رمز البريد، الدخول والخروج، والتنقل الموحد وحفظ ضيف على الجوال.
- نجح account-browser.cjs: التأكيد وMFA ورموز الاسترداد واستعادة كلمة المرور.
- نجح auth-design-browser.cjs على عروض 1440 و768 و390: كل شاشة، إظهار كلمات المرور، تذكر البريد ومسحه، منع تأكيد غير مطابق، اشتراط الموافقة، حفظ الاسم والموافقة في السجل الموجود، رابط الاستعادة الحقيقي والرد العام ورفض إعادة الاستخدام. يلتقط صورًا في /tmp/miqad-auth-*.png للمراجعة البصرية.

الاختبارات ترسل إلى محول وهمي فقط؛ لا تدعي إثبات التسليم من Resend أو جاهزية البريد العام على Render. وضع pilot وقيد حساب المالك يبقيان كما هما. للنشر، استخدم أحدث commit من render-setup دون تغيير متغيرات البيئة أو تشغيل initialize. لا يتغير GitHub Pages.
