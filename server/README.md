# مقعد — أساس SaaS للتطوير المحلي

هذه إضافة مستقلة إلى الموقع الموجود في جذر المستودع، وليست إطلاقًا إنتاجيًا أو اكتمالًا لتحويله إلى SaaS. تدعم واجهة الموقع الحالية وضع الشركات عبر الخادم مع استمرار وضع التخزين المحلي عند تشغيلها كملفات ثابتة. لا تتغير البيانات المحلية عند فتح شركة. اسم المالك المؤكد لخطة نقل البيانات: **شركة الطريفي**؛ لا ينشئ ذلك حسابًا إنتاجيًا أو ينقل البيانات تلقائيًا.

## التشغيل

المتطلبات: Node.js 22+، npm، وDocker يعمل محليًا. من مجلد `server`:

```sh
npm ci
node scripts/dev-db.mjs
npm run migrate
npm start
```

الخادم يستمع محليًا على المنفذ 8090؛ PostgreSQL على 15432. المسار `/console` لبوابة الشركات والتسجيل. المسار `/` يفتح الموقع أو يحيل إلى البوابة لاختيار مخطط. افتح بوابة التطوير محليًا، وأنشئ حساب اختبار بكلمة مرور مستقلة (12 حرفًا على الأقل). لا توجد بيانات دخول افتراضية. المتغير `PUBLIC_ORIGIN` يجب أن يطابق أصل الطلبات حرفيًا. لا تستخدم حسابات أو بيانات حساسة حقيقية في هذه التجربة.

ينشئ مساعد القاعدة عند أول تشغيل إعدادات محلية عشوائية داخل `.env` و`.local/postgres.env` بصلاحيات محدودة، وحاوية `miqad-saas-postgres` وحجم Docker دائم `miqad-saas-data` عند الحاجة. عند وجود حاوية سابقة يعيد استخدامها دون حذف أو تهيئة. الحاوية الحالية التي بدأت قبل إضافة المساعد محفوظة كما هي في حجمها الحالي؛ لا تحذفها. لا يحاول المساعد استبدال إعدادات اتصال موجودة أو إعادة إنشاء قاعدة مفقودة دون ملف إعدادها الأصلي. احتفظ بنسخ احتياطية؛ حجم Docker لا يمثل نسخة احتياطية ولا يُفترض أن ينتقل تلقائيًا بين البيئات السحابية.

لا تضف `.env` أو `.local/` إلى Git. `.env.example` توثيق يحتوي عناصر نائبة فقط. اتصال `DATABASE_ADMIN_URL` للترحيلات/أداة التهيئة والاختبارات المحلية فقط؛ التطبيق يستخدم ثلاثة أدوار منفصلة للمصادقة وعمليات الشركة وإدارة المنصة. لا تشغّل طلبات الشركة بحساب مالك الجداول.

## الوظائف المتاحة في بوابة التطوير

- تسجيل شركة ودخول وخروج بجلسة خادمية، والتبديل بين الشركات المرتبطة بالحساب.
- لوحة إحصائيات فعلية، فعاليات وقاعات متعددة، إنشاء مخطط صفوف وكراسٍ، إضافة ضيوف وتخصيص ونقل وتبديل وإخلاء الحجز.
- دعوات مقيدة بالبريد والدور، تغيير العضويات مع حماية آخر مالك، إدارة حالة الشركات لمالك المنصة فقط.
- معاينة واستيراد نسخة JSON قديمة إلى فعالية وقاعة جديدتين مع حفظ الأصل داخل سجل الاستيراد ومنع تكرار النسخة.
- بنية خطط واشتراكات فقط، دون دفع أو تفعيل تجاري.

لمنح **حساب موجود** دور مالك المنصة، ينفذ مشغل قاعدة التطوير الموثوق:

```sh
node --env-file=.env scripts/bootstrap-admin.mjs owner@example.test
```

لا تمنح واجهة التسجيل هذا الدور. حساب مالك الشركة لا يساوي مالك المنصة. لا تُمنح إدارة المنصة صلاحية SQL للاطلاع على بيانات الضيوف التشغيلية.

الدعوات تعرض رمزًا لمرة واحدة في التطوير بدل إرسال بريد. يحتاج المدعو إلى حساب بنفس البريد لقبولها. أدوار الشركة: مالك، مدير، منظم، قارئ، استقبال. الاستقبال محجوب عن البيانات التشغيلية حتى تنفيذ عرض محدود خاص به؛ ليس شاشة حضور مكتملة.

## الاختبارات

على قاعدة تطوير منفصلة عن أي بيانات إنتاج:

```sh
npm test
node test/console-browser.cjs
```

اختبارات الخادم تتصل بقاعدة PostgreSQL فعلية وتضيف سجلات اختبار بأسماء فريدة، ولا تمسح الجداول. اختبارات العزل تشمل API وSQL وRLS القسري، العلاقات المركبة، صلاحيات العضويات، آخر مالك، انتهاء الجلسة، الحجز المتزامن، النسخ القديمة، دور المنصة، منع تشغيل الإنتاج. اختبار المتصفح يحتاج Chromium وPlaywright؛ في البيئة الحالية تتوافر مساراتهما الافتراضية في ملف الاختبار. يمكن تخصيص `PLAYWRIGHT_MODULE` و`CHROMIUM_PATH` و`MIQAD_TEST_ORIGIN`. شغّل الخادم أولًا.

اختبارات الجذر تخص الموقع الحالي وليست بديلًا لاختبارات SaaS. لا تغيّر بيانات الموقع المنشور بغرض الاختبار.

## نقل البيانات الحالية

لم يُستورد أي ملف مستخدم حقيقي. خذ نسخة احتياطية من المتصفح الذي يحتوي البيانات الأصلية، ثم استخدم بوابة الاستيراد بالملف. تدعم قيمة `miqadStateV2` أو قائمة `miqadGuests` القديمة. اختر الشركة المقصودة، عاين الأعداد ثم أكد. تبقى بيانات المتصفح كما هي، ويحتفظ الخادم بالنسخة المستوردة كاملة. ترفض البيانات المتضاربة بدل تجاهل حجز أو تحويله تلقائيًا إلى الانتظار. لا تستنتج ملكية بيانات متصفح لمجرد تسجيل الدخول.

## حدود هذه المرحلة والخطوات التالية

أصبحت واجهة الموقع الأصلية متاحة عبر `/site/?tenant=…&workspace=…` من رابط «فتح المخطط في موقع مقعد» داخل بوابة الشركات. تعمل نوافذ الضيوف والوفود والتحكم بالصفوف والمقاعد والسحب والتبديل والبحث على بيانات الخادم؛ تُرسل التغييرات كوحدة واحدة بعد التحقق، ولا يظهر نجاح الحفظ قبل إتمامه. تمنع بصمة النسخة الكتابة القديمة، وتبقى معرّفات الحجوزات القائمة دون تغيير عند عدم تغييرها. الحجوزات في القاعات الأخرى محمية، ويظهر ضيفها بموقعه العام دون احتسابه في الانتظار أو إعادة تخصيصه. صلاحيات الاستقبال وشاشة الحضور لم تكتمل بعد. لا تدّعِ اكتمال المرحلة الأولى أو استخدام قاعدة مشتركة آمنة في النسخة المنشورة قبل إنهاء الربط والتحقق.

يمنع الخادم صراحة التشغيل بقيمة `NODE_ENV=production`. قبل الإطلاق: إعداد الاستضافة وTLS والنسخ الاحتياطي واختبار الاستعادة، تأكيد البريد والاستعادة وMFA لحسابات الإدارة، إرسال الدعوات، مراجعة الأمان والمراقبة وإدارة الأسرار، استكمال وظائف الحضور وصلاحيات الاستقبال، ثم نقل تجريبي مصرح به ومطابقة كل حجز. GitHub Pages لا يشغّل خادم Node أو PostgreSQL. لم يُنشر هذا الخادم أو تُفعّل المدفوعات.
