# مقعد

تطبيق عربي باتجاه RTL لتنظيم الضيوف وكبار الشخصيات وتوزيعهم على صفوف أفقية، في كل منها 15 كرسيًا.

## التشغيل

لا توجد حزم تشغيل أو خطوة بناء. من جذر المستودع:

```sh
python3 -m http.server 8010 --bind 127.0.0.1
```

تخدم هذه العملية `index.html` و`styles.css` و`app.js`. يمكن استضافتها كملفات ثابتة لاحقًا بعد المراجعة.

## استخدام المقاعد والصفوف

- يبدأ المخطط بثلاثة صفوف. من «إعدادات الصفوف» يمكن تحديد 1–50 صفًا وتسمية كل صف؛ يبقى كل صف 15 كرسيًا مرقمًا من 1 إلى 15.
- لكل كرسي معرّف ثابت بصيغة `رقم الصف:رقم المقعد` مثل `2:5`. تغيير اسم الصف لا يغير هويته أو تخصيصاته؛ الصفوف المضافة بعد حذف صف لا تعيد استخدام هويته.
- الضغط على كرسي فارغ يفتح نافذة الاسم والمسمى الوظيفي والجهة وصفة كبار الشخصيات والملاحظات. يمكن اختيار ضيف محفوظ بانتظار مقعد بدل إنشاء سجل جديد.
- الضغط على كرسي مشغول يعرض البيانات ويسمح بتعديلها أو إخلاء الكرسي بعد تأكيد. الإخلاء ينقل الضيف إلى الانتظار ولا يحذفه. يظل الحذف النهائي متاحًا بتأكيد من قائمة الضيوف.
- تقليل الصفوف يتطلب تأكيدًا وينقل ضيوف الصفوف المحذوفة إلى الانتظار مع الاحتفاظ بكل بياناتهم. تغيير العدد أو الأسماء لا يحذف الضيوف.
- «بحث عن المقعد» قسم مستقل للعرض فقط. البحث برقم المقعد يعرضه في جميع الصفوف، وبالمعرّف مثل `2:5` يحدد كرسيًا واحدًا. يدعم البحث الاسم والجهة والأرقام العربية واللاتينية.

## الحفظ ونقل البيانات القديمة

تُحفظ الصفوف والضيوف معًا تلقائيًا في `localStorage` تحت المفتاح `miqadStateV2`. عند أول فتح، تُنقل بيانات `miqadGuests` إذا لم توجد بيانات جديدة، ويُحتفظ بالمفتاح القديم دون تغيير كنسخة قابلة للاسترجاع. المقاعد القديمة 1–15 تُنقل إلى الصف الأول و16–20 إلى الصف الثاني، والتخصيصات المتعارضة أو غير الصالحة تصبح في الانتظار دون حذف الأشخاص. يبقى حقل المسمى القديم محفوظًا كما هو، دون تخمين ما إذا كان جهة أم مسمى وظيفيًا.

فشل الحفظ لا يعتمد التغيير أو يعرضه على الكرسي كأنه محفوظ. البيانات التالفة لا تُستبدل ببيانات فارغة. أي تحديث من نافذة أخرى يمنع الكتابة فوقه من نسخة قديمة حتى تحديث الصفحة. هذه حماية من الكتابة المتأخرة وليست قفلًا موزعًا؛ التطبيق محلي لمتصفح وجهاز وأصل موقع واحد، ولا يوفر مزامنة متعددة المستخدمين أو قاعدة بيانات.

## الاختبار

`tests/browser.cjs` يشغّل اختبارات فعلية في Chromium باستخدام Playwright. ثبّت أداة الاختبار خارج المستودع للحفاظ على عدم وجود اعتماديات تشغيل:

```sh
npm install --prefix /tmp/miqad-tools --cache /tmp/miqad-npm-cache playwright
PLAYWRIGHT_BROWSERS_PATH=/tmp/miqad-browsers /tmp/miqad-tools/node_modules/.bin/playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/tmp/miqad-browsers PLAYWRIGHT_MODULE=/tmp/miqad-tools/node_modules/playwright MIQAD_URL=http://127.0.0.1:8010 node tests/browser.cjs
```

عند وجود Chromium مثبت مسبقًا، يمكن تعيين `CHROMIUM_PATH` إلى مساره بدل تنزيل متصفح جديد. شغّل الخادم قبل الاختبارات. الاختبارات تستخدم سياق متصفح معزولًا وتغطي إدارة الضيوف، المقاعد، البحث، الحفظ والاستعادة، البيانات القديمة، فشل التخزين، حماية عرض النصوص، وعدم تجاوز عرض الشاشة عند 320 و390 و768 بكسل.

تُنقل تحديثات الموقع إلى فرع `main`. تشغيل GitHub Pages وإتمام النشر يعتمدان على إعدادات المستودع؛ نجاح رفع الفرع لا يثبت اكتمال النشر.
