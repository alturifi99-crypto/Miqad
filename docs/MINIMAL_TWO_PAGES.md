# واجهة مقعد: صفحتان

`/seating` هي الصفحة الرئيسية بعد تسجيل الدخول، و`/guests` صفحة مستقلة لجدول الضيوف. يحمل الرابط سياق tenant وworkspace، ويُتحقق من الجلسة والعضوية عبر API ثم RLS في الخادم. روابط `/` و`/site/` القديمة تصل إلى مخطط المقاعد مع حفظ سياقها. رابط قسم الضيوف القديم يتحول إلى المسار المستقل.

تحتوي القائمة الظاهرة على مخطط المقاعد وإدارة الضيوف فقط. تبقى واجهات API للفعاليات والقاعات والموظفين والاستيراد وإدارة المنصة وصلاحياتها موجودة. شاشة المصادقة الحالية مستمرة، ولا تظهر لوحة الإدارة القديمة بعد الدخول. إذا لم يوجد مخطط، يظهر زر بدء واحد؛ النقر عليه ينشئ مخططًا داخل الشركة الحالية، ويستخدم فعاليتها وقاعتها الموجودتين إن توفرتا. الطلب معاملاتي ومقيد بالشركة صراحةً وبـRLS، ومتكرر بأمان دون إنشاء مخطط ثانٍ عند تزامن الطلبات.

المقاعد تستخدم أدوات الإصدار الحالي مع منصة خضراء منحنية وصفوف مباشرة أسفلها، وزر إضافة صف وأزرار زيادة ونقص وحذف لكل صف، وتكبير وتصغير وملء الشاشة وتمرير داخلي. تستمر إضافة ضيف أو تجليس ضيف منتظر من نافذة الكرسي، والتعديل والإخلاء والتحريك والتبديل. المعرفات المخزنة للصفوف والمقاعد لا تتغير عند ترقيم الصفوف الظاهر تلقائيًا. حذف كرسي مشغول أو صف يتطلب التأكيد، ويحفظ بيانات الضيوف مع إعادتهم إلى الانتظار.

جدول الضيوف لا يحتوي على مخطط أو أرقام مقاعد. أعمدته الرقمية والاسم والمنصب والجهة، مع زر حذف. التحرير يتم داخل الخلايا، والحفظ تلقائي بعد التوقف عن الكتابة أو مغادرة الخلية. الصف الفارغ مسودة في الصفحة حتى إدخال اسم صحيح. البحث بالاسم أو الجهة. يدعم اللصق النصي من Excel حتى 1000 صف في الدفعة، بثلاثة أعمدة أو رقم تسلسلي ثم الأعمدة الثلاثة، واقتباس TSV وفواصل الأسطر. نسخ خلية محدد نصها يبقي السلوك الطبيعي؛ النسخ من خلية دون تحديد نص ينسخ بيانات الصف بثلاثة أعمدة TSV.

حفظ الجدول يحدث داخل معاملة بقفل الشركة ومراجعة revision. لا يكتب إلا name وtitle وorganization؛ يبقى VIP والمرافقون والملاحظات وsource_record والوفود والحجوزات كما هي. لا تُحذف سجلات غائبة عن الدفعة. حذف ضيف غير مرتبط يحتاج تأكيدًا صريحًا؛ تُرفض إزالة ضيف له حجز أو عضوية وفد حتى يُفك ارتباطه صراحةً. دفعة تحتوي على معرّف من شركة أخرى تتراجع كاملةً. القراءة متاحة للقارئ، والكتابة لأدوار التحرير فقط.

عند التعارض أو فشل الحفظ تبقى التعديلات المحلية مع رسالة وإمكانية المحاولة عندما توجد بيانات معلقة؛ لا تُستبدل تلقائيًا بنسخة أقدم. يحذر المتصفح عند مغادرة صفحة تحتوي على مسودات غير محفوظة. لا تُستخدم بيانات localStorage بدل بيانات الشركة، ولا تُحذف النسخة المحلية القديمة. لا توجد ترحيلات أو تغييرات بنية قاعدة أو إعادة تعيين بيانات.

التحقق: 40 اختبار خادم ناجح، بما فيها حفظ الحجوزات ومعرّفاتها وVIP والوفود، الحذف المحمي، رفض القارئ، منع الوصول بين شركتين، والتراجع الكامل عن دفعة مخالفة. minimal-browser.cjs اختبر تسجيل الدخول الحقيقي مع بريد محاكى، فتح المقاعد افتراضيًا، قسمين فقط، أدوات الصفوف والكراسي والتأكيدات، إعادة تجليس ضيف، تحرير الجدول والحفظ والتحديث، اللصق والنسخ والبحث والحذف، بقاء التعديل المحلي عند تعارض نافذتين، وقائمة الآيفون والتكبير دون تمرير عام زائد. نجحت اختبارات account-browser وemail-login-browser وauth-design-browser؛ وأيضًا tests/browser.cjs للنسخة الأصلية، بما فيها التحريك والتبديل والنسخ القديمة وعروض 320/390/768/1440. صور المراجعة في /tmp/miqad-simple-*.png.

للتفعيل على Render، انشر أحدث commit من render-setup فقط. اترك DEPLOYMENT_MODE=pilot وDATABASE_SETUP=check وبقية الإعدادات كما هي. تبسيط الواجهة لا يفتح التسجيل العام أو يتجاوز قيد مزود البريد.

## تحسين مساحة المقاعد

أضيف شريط علوي مختصر بعنوان الصفحة واسم الفعالية الفعلي من بيانات المخطط، وقُلص عرض القائمة إلى 194 بكسل على الكمبيوتر مع بقاء الطي ودرج الجوال. صُغرت المنصة المنحنية والكراسي والمسافات بين الصفوف، وأزيل الحد الأدنى القديم لارتفاع مساحة العمل الذي كان يترك فراغًا كبيرًا. مفتاح الحالات يظهر أسفل المخطط: متاح، محجوز، كبار الشخصيات، ومحدد.

في الواجهة السحابية المبسطة، اسم الصف زر قابل للتحديد باللمس وEnter. تحديد صف يعرض أدواته وحدها، واختيار كرسي يحدد صفه أيضًا، وإضافة صف تفتح أدوات الصف الجديد. هذه حالة عرض مؤقتة في الذاكرة لا تُكتب إلى API أو قاعدة البيانات. أزرار الجوال بحجم لمس مناسب وتبقى ظاهرة داخل عرض الشاشة عند التكبير. لا تتغير قواعد الحفظ أو التأكيد أو بيانات الصفوف والضيوف والحجوزات؛ لا يوجد ترحيل أو تغيير خادم لهذا التحسين.

اجتاز minimal-browser.cjs فحص عنوان الفعالية، حجم الشريط والقائمة، إظهار الأدوات بلوحة المفاتيح واللمس، وعدم حدوث كتابة عند تحديد الصف، وبقاء الأزرار والمنصة داخل الشاشة، وإغلاق درج الجوال من خارجه دون تغيير عرض المحتوى، مع اختبارات التحرير والحجوزات والجدول المستقل السابقة. نجح tests/browser.cjs أيضًا لوظائف النسخة الأصلية وتحريك الضيوف والتبديل والتأكيدات والتخزين وعروض 320/390/768/1440.
